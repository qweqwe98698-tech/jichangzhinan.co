## 01. 常见故障高频诊断 20 大速查百科

为了帮助大家在遇到任何网络断连或节点异常时能够在 30 秒内自救，编辑部整理了业界最全面的 **20 大常见高频问题与精准一键修复清单**：

| 序号 | 故障现象 | 最核心根本原因 | 30 秒一键修复步骤 |
| :---: | :--- | :--- | :--- |
| **01** | **所有节点全部测速超时 (Timeout)** | 本地电脑时间与北京时间误差超过 60 秒 | Windows 设置 -> 时间和语言 -> 点击「立即同步」 |
| **02** | **关掉代理后电脑全网断网打不开网页** | 系统代理注册表开关残留未关闭 | Windows 设置 -> 网络和 Internet -> 代理 -> 手动关闭 |
| **03** | **节点测速是绿色但浏览器打不开 Google** | 客户端只打开了软件，未开启「系统代理」 | 在主界面勾选「系统代理 (System Proxy)」开关 |
| **04** | **订阅链接更新提示 Network Error / 403** | 订阅 URL 被本地运营商 DNS 污染拦截 | 开启已有可用节点后点击「通过代理更新订阅」 |
| **05** | **提示 7890 或 10808 端口被占用** | 后台存在残留未杀死的代理核心进程 | 任务管理器强制结束 `clash-meta.exe` 或 `xray.exe` |
| **06** | **微信 QQ 正常，但任何浏览器打不开网页** | 分流规则将浏览器流量错误路由到了死节点 | 客户端切换为 `Global (全局代理)` 测试或更换主节点 |
| **07** | **访问 ChatGPT 提示 Access Denied 1020** | 节点出口 IP 属于万人共用的机房脏 IP | 切换至具备原生家庭宽带属性的美国或日本专线节点 |
| **08** | **Netflix 只能看自制剧搜不到版权大片** | 节点出口 IP 被 Netflix 风控降级 | 切换至支持原生家庭住宅 IP 解锁的流媒体专线 |
| **09** | **Claude 3.5 提示 Unable to serve request** | 使用了香港、俄罗斯等不支持该服务的节点 | 策略组中将 Claude 强制切换到美国或日本节点 |
| **10** | **Apple TV 看 Netflix 提示检测到代理** | Apple TV 默认 IPv6 泄漏了真实国内 IP | 在代理客户端或路由器中开启「禁用 IPv6」 |
| **11** | **Steam 游戏延迟极高或频发跳 Ping** | 未开启虚拟网卡或节点不支持 Full Cone NAT | 开启客户端「TUN 模式」，切换至低延迟 IEPL 专线 |
| **12** | **iOS 无法在 App Store 搜到小火箭** | 中国区 App Store 已下架所有网络工具 | 登录美区或港区 Apple ID 购买下载正版 |
| **13** | **macOS 安装服务模式提示 Helper 失败** | macOS 系统缺少安全执行权限 | 终端运行 `sudo /Applications/Clash.app/Contents/MacOS/clash` |
| **14** | **微信小程序与国内银行 App 加载极慢** | 国内常用域名被误判走了海外代理 | 在规则中置顶 `GEOSITE,cn,DIRECT` 白名单 |
| **15** | **Subconverter 转换后的订阅文件为空** | 原始订阅格式不支持或被后端 WAF 拦截 | 使用私有 Docker 本地转换后端 |
| **16** | **软路由开启后全屋米家智能家居离线** | 主路由与旁路由 DHCP 冲突形成广播风暴 | 采用 Dnsmasq Option 3/6 对特定 MAC 精准分流 |
| **17** | **Telegram 一直显示 Connecting 转圈** | Telegram 默认不读系统代理 | Telegram 设置 -> 高级 -> 连接类型填 `SOCKS5 127.0.0.1:7890` |
| **18** | **CMD / PowerShell / Git 命令行不走代理** | CLI 终端原生不继承 Windows 注册表代理 | 终端执行 `set http_proxy=http://127.0.0.1:7890` 或开 TUN |
| **19** | **迅雷 / BT 下载把机场月度流量瞬间跑光** | P2P 流量误走高成本专线节点 | 规则中配置 `PROCESS-NAME,Thunder.exe,DIRECT` 直连 |
| **20** | **机场账户余额突然被扣光** | 误选了 5x-10x 的倍率刺客节点 | 检查节点列表倍率，日常固定使用 1.0x 标准倍率 |

## 02. 四大核心故障深度实操指南

### 1. 系统时间同步（解决 90% 的节点超时）
由于现代加密协议（VLESS、VMess、Trojan、Reality）采用了严格的时间戳防重放攻击校验，一旦本地时钟偏差超过 90 秒，服务器会在底层直接拒绝 TLS 握手：
- **Windows 修复**：按下 `Win + I` 打开系统设置 -> 点击「时间和语言」->「日期和时间」-> 点击「立即同步」按钮。
- **macOS 修复**：打开「系统设置」->「通用」->「日期与时间」-> 开启「自动设置时间」。

### 2. 彻底解决关软件后的断网问题
当代理软件异常闪退时，Windows 系统代理注册表未能还原：
- 按下 `Win + R` 输入 `inetcpl.cpl` 打开 Internet 属性；
- 切换到「连接」标签页 -> 点击「局域网设置」；
- **取消勾选「为 LAN 使用代理服务器」** -> 点击确定保存即可立刻恢复上网！
