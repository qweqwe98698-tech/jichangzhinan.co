## 01. 认识 Shadowrocket：iOS 平台的“装机必备”神器

**Shadowrocket（俗称“小火箭”）** 是 iOS 与 iPadOS 平台上历史最悠久、装机量最大、兼容性最广泛的规则分流代理工具。

它的标志是一枚精美的白色火箭图标（售价 $2.99 美元，由开发者 Liggg Developer 维护）。小火箭以**极低的电池功耗、秒级快速连接、全面的协议兼容（Shadowsocks, VLESS, Trojan, Hysteria 2）以及丰富的去广告与规则重写生态**，成为了亿万苹果用户的科学上网首选。

## 02. 下载与准备：获取海外 Apple ID

由于国区政策限制，下载 Shadowrocket 需要使用非大陆地区的 Apple ID：

1. **登录海外 Apple ID**：打开 iPhone 的 `App Store` -> 点击右上角个人头像 -> 滑到最底部点击「退出登录」-> 登录准备好的美区或港区 Apple ID。
2. **购买与安装**：在搜索栏输入 `Shadowrocket`，认准原作者图标，使用外区礼品卡或信用卡支付后完成安装。
3. **安全提醒**：下载完成后，建议立刻在 App Store 中切回你自己的国区常用账号，切勿在 iPhone 系统设置中的「iCloud」登录他人提供的共享账号，以防手机被恶意锁定！

## 03. 订阅导入与自动更新实操

1. 打开 [光速云](/airports/)、[星岛梦](/airports/) 或你所使用的机场用户中心，复制 **Shadowrocket 一键导入链接** 或 **通用 V2Ray / Clash 订阅 URL**。
2. 打开 Shadowrocket 应用：
   - 如果复制了导入链接，打开软件时会自动弹出「发现剪贴板中的订阅，是否添加？」点击「添加」即可。
   - **手动添加**：点击右上角 **「+」号** -> 类型选择 `Sub / Subscribe` -> 在 URL 输入框中粘贴订阅地址 -> 备注输入机场名称（如“光速云 IEPL”）-> 点击右上角「保存」。
3. **开启自动更新**：进入底部「设置」->「订阅」-> 开启 **「打开时更新」** 与 **「自动后台更新」**，确保节点列表每日自动与服务器同步。

## 04. 节点测速与全局路由模式解析

### 1. 节点测速与选择
- 点击主界面的 **「连通性测试」**（或 Ping 测试），列表将显示所有节点的真实网络延迟。
- 优先选择测速结果为绿色且数值在 **50ms ~ 120ms** 的专线节点，点击节点名前方的圆圈即可切换为主活动节点。

### 2. 四大全局路由模式详解
在主界面下方找到「全局路由」选项：

```text
┌─────────────────────────────────────────────────────────────────────────┐
```

## 05. 进阶实战：安装 MitM 证书实现广告拦截

若需使用去广告模块（如拦截 YouTube 或社交媒体开屏广告），需要配置本地解密根证书：

1. 进入底部 **「配置」** 页面 -> 点击默认的 `default.conf` -> 选择 **「编辑纯文本」** 或「HTTPS 解密」；
2. 开启「HTTPS 解密」开关 -> 点击 **「生成新的 CA 证书」** -> 点击「安装证书」；
3. 打开 iPhone 的 `系统设置` -> 提示「已下载描述文件」-> 点击安装；
4. 进入 iPhone `设置` -> `通用` -> `关于本机` -> 滑到最底部 `证书信任设置` -> 找到刚刚安装的 `Shadowrocket CA` -> **开启完全信任开关**。
